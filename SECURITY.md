# Security Policy

TV Companion talks to a TV on your local network and stores a pairing key in the Keychain. Please report vulnerabilities privately through GitHub's **Report a vulnerability** button (Security → Advisories) instead of a public issue.

In scope: transport security (TLS and certificate pinning), handling of the client key, input-capture behaviour, and anything that could let another device on the network control the Mac or the TV through this app.
